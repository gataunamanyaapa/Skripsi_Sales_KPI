# Employee Performance Analysis Using K-Means Clustering

## Project Overview

This project applies **K-Means Clustering**, an unsupervised machine learning algorithm, to analyze employee performance at **PT Gelatik Supra**, a sales and marketing outsourcing company. The project aims to transform employee KPI data into meaningful performance clusters, enabling managers to monitor workforce performance and make data-driven decisions.

Employee performance data can be challenging to evaluate manually due to its volume and distribution across different regions. This project addresses that challenge by developing a clustering model and an interactive dashboard that presents employee performance insights in a more accessible and structured format.

## Objectives

* Analyze employee performance based on selected Key Performance Indicators (KPIs).
* Apply K-Means Clustering to group employees according to their performance characteristics.
* Visualize employee performance distributions and cluster characteristics.
* Develop an interactive dashboard to support employee monitoring and HR evaluation.
* Provide insights to support managerial decisions regarding employee placement, training, and performance improvement.

## Key Performance Indicators

The clustering model uses four primary features:

* **Visit Frequency:** Measures employee store visit activity.
* **FIFO/FEFO Compliance:** Evaluates compliance with stock rotation practices.
* **Price Tag Availability:** Measures the availability of product price tags.
* **Facing:** Represents product-facing or shelf-display performance.

## Tech Stack

* **Programming Language:** Python
* **Data Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-learn, K-Means Clustering
* **Data Visualization:** Plotly
* **Dashboard Development:** Python-based interactive web dashboard
* **Development Environment:** Jupyter Notebook and Visual Studio Code

## Expected Outcomes

The project produces employee performance clusters, visualizations of cluster distributions, and an interactive dashboard that helps managers explore employee data and identify performance patterns.

The resulting insights can support more efficient employee evaluation, targeted training recommendations, and data-driven workforce management.

## Project Context

This project was developed as an undergraduate thesis in Information Systems, focusing on the application of data mining and machine learning to employee performance analysis.

**Note:** The resulting clusters represent patterns identified by the K-Means algorithm. They should be interpreted alongside business context and managerial evaluation rather than treated as definitive judgments of individual employee performance.
